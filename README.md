# Finance Tracker — личный трекер расходов

Мобильное PWA на русском: быстрый ввод в тенге, журнал, бюджет и офлайн-очередь. Один Cloudflare Worker раздаёт React-приложение и API; Google Sheets остаётся источником данных. Обычные расходы записываются только в `Ввод данных!A:E` и `G:H`. После вашего подтверждения настройки создают два служебных листа `FT Categories` и `FT Items`. Переименование/перенос категории меняет только соответствующие ячейки C журнала. Формула F и старые листы остаются нетронутыми.

## Локальный запуск

Нужен Node.js 24 и npm. В Windows PowerShell используйте `npm.cmd` и `npx.cmd`, если политика выполнения блокирует `.ps1`.

```powershell
npm.cmd ci
npm.cmd run dev
```

Откройте http://127.0.0.1:5173. Код локального mock-режима: `mock-local-key`. Это публичный тестовый код, не настоящий APP_KEY. `dev` принудительно использует mock даже при заполненном `.dev.vars`; Vite даёт горячее обновление, Worker работает на 8787. При первом запуске оболочка собирается автоматически. Mock содержит 60 расходов за три месяца и сбрасывается при перезапуске Worker.

Для проверки установленной оболочки и service worker используйте сборку на http://127.0.0.1:8787. На сервере Vite service worker отключён.

```powershell
npm.cmd run build
npx.cmd wrangler dev --port 8787 --var USE_MOCK:1 --var APP_KEY:mock-local-key
```

## Проверки

```powershell
npm.cmd run lint
npx.cmd tsc --noEmit
npm.cmd test
npm.cmd run build
npx.cmd playwright install chromium
npm.cmd run test:e2e
node scripts/check-secrets.mjs
```

Playwright сам запускает mock Worker, использует 412×915, DPR 2.6, светлую и тёмную темы. Освободите порт 8787 перед тестами. Скриншоты — `tests/screenshots`, отчёт — `playwright-report/index.html`. Unit/API не используют сеть. `npm run smoke:read` использует реальные секреты, но делает **только чтение** и выводит количество строк и результат сверки сумм без самих расходов. В проекте нет автоматически запускаемого live write smoke.

## Работа с приложением

Начальный экран — «Траты». Кнопка «+» открывает форму: наберите сумму своей клавиатурой, выберите категорию и сохраните. `1` → `000` → категория → сохранение — четыре касания внутри формы. Название необязательно; собственные подсказки помогают повторить привычную запись. Дата «Сегодня» следует времени Алматы; ручная дата сохраняется при переходе через полночь. Ссылка `/?amount=1200&merchant=Magnum&src=wallet` сама открывает форму, заполняет поля и очищает адресную строку.

«Обзор» переключается между месяцем и неделей с понедельника. Текущий период сравнивается с тем же количеством дней предыдущего; завершённый — со всем предыдущим. Столбец выбирает день, кольцо или строка легенды — категорию. «Показать все» открывает журнал с периодом и категорией. Малые доли объединяются только в кольце. Месячный график можно листать внутри карточки; недели помещаются целиком. Остаток = доходы − ежемесячные расходы − все личные траты, включая записи без категории. Дневной остаток делится на дни до конца текущего месяца, включая сегодня. Лимиты категорий влияют только на полосы категорий. В недельном режиме баланс остаётся месячным с явной подписью.

На ПК навигация слева, правка открывается рядом с журналом. `N` (или `Т`) — добавление, `/` — поиск, `←`/`→` — период, Escape — закрытие окна. В кольце и переключателе режимов стрелки управляют выбранным элементом. В форме суммы доступны цифры аппаратной клавиатуры. В «Ещё» можно выбрать системную/тёмную/светлую тему и скачать CSV за месяц.

В журнале нажмите запись для правки. Удаление доступно только в правке; «Отменить» — пять секунд до отправки на сервере. При 409 обновите список и откройте запись снова.

Очередь сохраняется в IndexedDB **до** подтверждения сохранения. При сбое сети запись получает задержку повтора, при 4xx (кроме 408/429) — статус ошибки; в журнале доступны «Повторить», «Исправить», «Убрать». Откройте приложение с интернетом для отправки: при старте, восстановлении сети и каждые 15 секунд выполняется последовательная синхронизация. Пока приложение закрыто, очередь хранится на устройстве. Один ID используется во всех попытках, вкладки согласуются через Web Locks и BroadcastChannel.

Код хранится в localStorage и локальном IndexedDB для очереди. Google-ключ браузер не получает. Выход удаляет активный код и историю, очередь шифруется прежним кодом. Перед сменой кода отправьте очередь. Не очищайте данные сайта с неотправленными расходами.

## Категории, доходы и обновления

- До создания настроек категории читаются из `Справочник!A3:B`, доходы и ежемесячные расходы — из `Доходы и расходы!M3:S`. Личные траты всегда считаются по журналу.
- «Ещё → Настройки → Создать» импортирует категории и историю шести статей в два новых служебных листа. Это действие подтверждается отдельно; открытие приложения не создаёт листы. Повтор не дублирует импорт.
- После создания меняйте статьи, категории и лимиты в приложении. Сумма применяется с выбранного месяца или только на этот месяц. Пустые месяцы продолжают последнее значение. Снятие статьи сохраняет прошлое; есть отмена в течение пяти секунд.
- Переименование показывает количество затронутых записей. Удаление категории означает архив либо перенос её записей в другую категорию с последующим архивом. Архив можно восстановить. Цвет привязан к ID. Валидация C в самом Google Sheets по старому справочнику может устаревать.
- Настройки кэшируются на пять минут; запись сбрасывает кэш. Конфликт rev возвращает 409: обновите страницу и повторите изменение. При сетевом сбое повторите сохранение в том же диалоге, чтобы завершить прежнюю операцию.
- F2 содержит ограниченную `ARRAYFORMULA` до строки 1006. При приближении к этому объёму вручную расширьте формулу и формат/валидацию A/C; приложение само их не меняет.
- Не сортируйте и не редактируйте строки вручную одновременно с сохранением в приложении. Sheets API не предоставляет атомарную проверку отпечатка против внешних редакторов. Запросы самого приложения сериализованы одним Durable Object.

Обновление после изменений:

```powershell
npm.cmd ci
npm.cmd run check
npm.cmd run build
npm.cmd run test:e2e
npm.cmd run deploy
```

Смена кода сервера (ввод секрета интерактивно, не в командной строке):

```powershell
npx.cmd wrangler secret put APP_KEY
```

Обновите также APP_KEY в своём `.dev.vars`, выйдите в «Ещё» и войдите с новым кодом. ## API

Все `/api/*`, включая health, требуют `X-App-Key`. CORS закрыт. Bootstrap возвращает категории, историю, расходы выбранного месяца и сводку. Создание требует уникальный ID вида `epochMs-UUID`; повтор возвращает ту же строку. Ручная категория обязательна. `/api/quick` допускает пустую категорию только при сохранении автоматической записи; для повторов нужен стабильный `id` из одного уведомления. Ошибки: JSON `{error,message}`, 401/429/422/409.

```text
GET    /api/health
GET    /api/bootstrap?month=2026-10
GET    /api/expenses?month=2026-10
POST   /api/expenses
PATCH  /api/expenses/:row   (тело с fp)
DELETE /api/expenses/:row?fp=...
POST   /api/quick
GET    /api/export.csv?month=2026-10
GET    /api/config
POST   /api/config/setup
POST   /api/config/categories[/id]   (operationId, rev для правки; ?dry=1 для предпросмотра)
POST   /api/config/items[/id]        (operationId, rev, month, amount, scope; remove=true для снятия)
```

Google API: чтение UNFORMATTED_VALUE/SERIAL_NUMBER, пакетные запросы; текст RAW защищает от формул, даты записываются числовым serial с сохранением существующего формата. Подробности контракта — [документация Google](https://developers.google.com/workspace/sheets/api/guides/values). Статика и API используют [Workers Static Assets](https://developers.cloudflare.com/workers/static-assets/binding/).

## Аккаунты: действия после обновления (PowerShell)

Выполняет владелец. Автоматическая публикация не создаёт Aru и не меняет пароли. При первом API-запросе создаётся только Tarlan из прежних секретов; Google-таблица при этом не меняется. Публичный список аккаунтов содержит логины и имена. Все остальные данные доступны только по сессии.

1. Откройте приложение, выберите **Tarlan · tarlan** и введите прежнее значение APP_KEY в поле пароля. Убедитесь, что данные на месте и старая очередь отправилась. APP_KEY больше не работает как API-токен; он нужен только для начальной миграции. Не очищайте данные сайта до проверки очереди.
2. Из корня проекта создайте административный токен в переменной, не выводя его на экран, и загрузите секрет:

```powershell
$env:WORKER_URL = 'https://finance-tracker.tarlan-b06.workers.dev'
$env:ADMIN_TOKEN = node -e "process.stdout.write(require('node:crypto').randomBytes(32).toString('hex'))"
$env:ADMIN_TOKEN | npx.cmd wrangler secret put ADMIN_TOKEN
node scripts/accounts.mjs list
node scripts/accounts.mjs add aru Aru --must-change
```

Последняя команда дважды запросит пароль скрытым вводом. Не передавайте пароль аргументом, в URL или через командную историю. Сохраните ADMIN_TOKEN в менеджере паролей; при необходимости добавьте его в игнорируемый .dev.vars. Не создавайте новый токен при каждом запуске: после закрытия терминала загрузите сохранённое значение в окружение или .dev.vars. В .dev.vars.example только имена переменных, без значений.

3. Aru создаёт **пустую Google-таблицу** и даёт сервисному аккаунту доступ «Редактор». Привяжите её (замените текст в угловых скобках):

```powershell
node scripts/accounts.mjs set-sheet aru '<ссылка Google Sheets или ID>'
```

Команда выводит email сервисного аккаунта из конфигурации Worker; если доступ ещё не выдан, выдайте его сейчас до подготовки. Приватный ключ не выводится. Одну таблицу нельзя привязать к двум аккаунтам. При смене уже подключённой таблицы сначала отправьте очередь всех устройств и завершите их сессии; иначе неотправленные расходы аккаунта попадут в новую привязку.

4. Aru выбирает свой аккаунт, вводит временный пароль, задаёт новый, затем нажимает **«Подготовить таблицу»**. Старые таблицы с листом расходов эта операция не меняет. Добавляются журнал на 1006 строк, формула месяца, FT Categories и FT Items. Начальные лимиты — 0, доходных и ежемесячных статей нет: заполните их в настройках. Затем можно записывать траты.

Администрирование (все команды ниже изменяют аккаунты, выполняйте осознанно):

```powershell
node scripts/accounts.mjs list
node scripts/accounts.mjs set-password aru --must-change
node scripts/accounts.mjs revoke aru
node scripts/accounts.mjs disable aru
node scripts/accounts.mjs enable aru
# Отзыв отдельной сессии (ID из интерфейса/управления сессиями):
node scripts/accounts.mjs revoke aru --session '<ID сессии>'
```

Сброс пароля отзывает все сессии; смена пароля в приложении — остальные. «Ещё → Аккаунт» показывает устройства и позволяет завершить отдельный сеанс. Для выхода с серверным отзывом нужен интернет. Очередь при выходе шифруется постоянным ключом аккаунта и восстанавливается после входа в тот же аккаунт, даже после смены пароля. Браузерная очистка данных уничтожает неотправленную очередь.

Проверка публикации: node scripts/verify-deployment.mjs https://finance-tracker.tarlan-b06.workers.dev. Без VERIFY_LOGIN/VERIFY_PASSWORD проверяются только публичные endpoints и 401. Для чтения данных владелец задаёт эти переменные в игнорируемом .dev.vars; скрипт входит, читает и завершает свою сессию, не пишет в Sheets. Административный токен для этой проверки не нужен.
