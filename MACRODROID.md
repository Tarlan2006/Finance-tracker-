# MacroDroid: открыть форму после платежа

Режим А — основной: уведомление → готовая сумма и магазин → выбор категории → «Сохранить». Уведомление само по себе ничего в таблицу не пишет. Настройка ниже — шаблон: настоящих текстов Wallet и Kaspi пока нет, названия действий зависят от языка/версии MacroDroid.

Описание триггера и полей текста: [MacroDroid Wiki — Notification](https://www.macrodroidforum.com/wiki/index.php?title=Trigger:_Notification).

## 1. Разрешения на Samsung

1. Установите MacroDroid, откройте его и создайте макрос кнопкой «Добавить макрос».
2. Для триггера уведомлений разрешите **доступ к уведомлениям** в открывшемся системном разделе Android. Это отдельное разрешение от показа собственных уведомлений.
3. Samsung: Настройки → Приложения → MacroDroid → Батарея → «Без ограничений». В «Обслуживание устройства» → «Батарея» → ограничения фонового использования уберите MacroDroid из спящих приложений, если он там есть.
4. Разрешите действие открытия браузера. Установите Chrome браузером для ссылки приложения.

## 2. Отдельный макрос Google Wallet

1. «Триггеры» → «События устройства» / «Уведомление» → «Уведомление получено».
2. Выберите **Google Wallet** из списка установленных приложений, только уведомления о состоявшемся платеже. Не выбирайте все приложения.
3. Сохраните полный текст уведомления в строковую переменную `notification` через «магический текст» самого триггера. Вариант поля/название переменной возьмите из текущего интерфейса MacroDroid.
4. Тестовый материал для замены: `<<ТЕКСТ_УВЕДОМЛЕНИЯ_WALLET>>`.
5. В действии обработки текста / извлечения регулярным выражением выделите сумму первой группой:

   ```regex
   (\d[\d\s\u00A0]*(?:[,.]\d{1,2})?)\s*(?:₸|тенге|KZT)
   ```

6. Магазин в условном формате «Оплата 1 200,00 ₸ Magnum» находится после валюты:

   ```regex
   (?:₸|тенге|KZT)\s*[—:–-]?\s*(.+)$
   ```

7. У суммы уберите обычные/неразрывные пробелы, запятую замените точкой. Если сумма не распознана, остановите макрос; не подставляйте 0.
8. Выполните URL-кодирование UTF-8 для суммы и магазина отдельным действием обработки текста. Если версия MacroDroid предлагает кодирование в настройках URL, используйте его один раз, без повторного кодирования.
9. «Действия» → «Открыть веб-сайт / URL»:

   ```text
   https://<<WORKER_URL>>/?amount=<<URL_ENCODED_AMOUNT>>&merchant=<<URL_ENCODED_MERCHANT>>&src=wallet&ts=<<EPOCH_SECONDS>>
   ```

   Вставляйте переменные через встроенный выбор «магического текста»; `<<…>>` — места замены, не буквальный синтаксис MacroDroid. Параметр ts необязателен, это Unix-время в секундах для предупреждения о дублях.
10. Пример сформированной ссылки: `https://<<WORKER_URL>>/?amount=1200.50&merchant=Magnum&src=wallet`. Ключ доступа в URL не нужен и никогда туда не добавляется.
11. Chrome откроет форму; сумма и название подставятся. При двух и более совпадениях в истории категория будет предложена. Проверьте её и сохраните. Адрес очистится после разбора параметров.

## 3. Отдельный макрос Kaspi

Скопируйте макрос Wallet, замените приложение триггера на **Kaspi.kz** из списка установленных. Не вводите предполагаемое имя Android-пакета: проверьте выбранное приложение на своём телефоне. Параметр `src=kaspi`. Материал для настройки: `<<ТЕКСТ_УВЕДОМЛЕНИЯ_KASPI>>`.

До извлечения суммы добавьте условия:

| Операция | Действие |
|---|---|
| Покупка / оплата по QR | Открыть форму расхода |
| Исходящий перевод другому человеку | Открыть форму расхода |
| Входящий перевод, «вам перевели», зачисление, пополнение | Пропустить |
| Перевод между своими счетами / на свой депозит | Пропустить |
| Неясный текст или отсутствующая сумма | Не записывать автоматически, проверить вручную |

Пример отрицательного фильтра, который **нужно уточнить по настоящим уведомлениям**:

```regex
(?i)пополн|зачислен|входящ|вам перев|между сво|на свой|своими счет
```

Отдельно задайте положительный фильтр покупок/оплат/исходящих переводов по вашим реальным текстам. Одного отрицательного фильтра недостаточно для автоматического режима: слова «перевод» и сумма могут встречаться и в рекламных уведомлениях.

## 4. Проверка шаблонов

Чистая функция `shared/parse-notification.ts` покрыта тестами на вымышленных примерах:

- `Оплата 1 200,00 ₸ Magnum` → 1200, Magnum.
- `1200 ₸ — Magnum` → 1200, Magnum.
- `Покупка QR 1 200 KZT: Magnum` → 1200, Magnum.
- `Исходящий перевод 1200 ₸ Иван` → расход.
- `Вам перевели 1200 ₸`, пополнение и перевод себе → пропуск.

Функция в приложении служит проверяемым шаблоном, она не читает уведомления Android. Не выдавайте эти примеры за реальные тексты банков. До использования сравните группы регулярки в MacroDroid и результат функции на одинаковом обезличенном тексте.

Чтобы один платёж не открывался несколько раз при обновлении уведомления, сохраните последнюю комбинацию «приложение + ID уведомления + сумма + магазин + время события» и пропускайте её повторы. В приложении остаётся предупреждение о возможном дубле.

## 5. Будущий режим Б: без открытия формы

API уже имеет `POST /api/quick`; сценарий в MacroDroid пока не настроен и на настоящих уведомлениях не проверен. После проверки фильтров можно добавить HTTP POST:

```text
URL: https://<<WORKER_URL>>/api/quick
Content-Type: application/json
X-App-Key: <<APP_KEY>>
```

```json
{"id":"<<EPOCH_MS-UUID_ОДНОГО_СОБЫТИЯ>>","amount":1200,"merchant":"Magnum","src":"kaspi","save":true}
```

`save: 1` тоже поддерживается. **Дополнение к базовому контракту:** для `save=true` обязателен стабильный `id`, созданный один раз для уведомления. Повторы HTTP обязаны использовать тот же ID, иначе возможна повторная трата. Для получения только подсказки передайте `save:false`; ID тогда не нужен.

Если категория не определена уверенно, создаётся запись без категории с источником `kaspi-auto` / `wallet-auto`, она появляется сверху журнала в «Нужно проверить». В ответе есть краткий `text`, его можно показать уведомлением MacroDroid. При 401 проверьте код, при 429 подождите, при 422 исправьте данные; не генерируйте новый ID для сетевого повтора.

Храните код только в защищённой переменной вашего устройства. Экспортируемый макрос не должен содержать APP_KEY. Импорт старых Excel, сверка с Kaspi и редактирование лимитов из приложения — отдельные будущие задачи.
