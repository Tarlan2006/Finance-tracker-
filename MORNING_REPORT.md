## Что сделать утром

1. Открыть https://finance-tracker.tarlan-b06.workers.dev в Chrome и войти с существующим APP_KEY из своего `.dev.vars`. Секрет намеренно не включён в отчёт.
2. Chrome → ⋮ → «Добавить на главный экран» / «Установить приложение». Физическая установка на Samsung и разрешение микрофона требуют телефона; эмуляция Chromium их не заменяет.
3. Настроить MacroDroid по [MACRODROID.md](MACRODROID.md). Взять настоящие тексты Wallet/Kaspi, подогнать регулярки и фильтры входящих/своих переводов. Начать с открытия формы, не с автосохранения.
4. При желании повторить безопасную проверку опубликованного сервера:

   ```powershell
   node scripts/verify-deployment.mjs https://finance-tracker.tarlan-b06.workers.dev
   ```

5. Для локальной демонстрации из корня проекта:

   ```powershell
   npm.cmd ci
   npm.cmd run dev
   ```

   Адрес http://127.0.0.1:5173, тестовый код `mock-local-key`. Для реальных данных локально — `npm.cmd run dev:live` и порт 8787.
6. Для будущего обновления после изменения кода:

   ```powershell
   npm.cmd run check
   npm.cmd run build
   npm.cmd run test:e2e
   npm.cmd run deploy
   ```

   Перед e2e остановить локальный dev, чтобы освободить 8787. Если секреты изменились: `npx.cmd wrangler secret bulk .dev.vars`. Полная первичная настройка и команды — [MANUAL_STEPS.md](MANUAL_STEPS.md).

## Допущения и известные ограничения

- После публикации `workers.dev` **иногда возвращал платформенную HTML-страницу 404** вместо Worker. Повторно применён маршрут; полный smoke завершился успешно. После последнего deploy потребовался один повтор через 2 секунды. Причина внутри Cloudflare не установлена; это не объявляется исправленной ошибкой приложения. Если встретите 404, повторите открытие и команду проверки выше. Скрипт делает максимум четыре повтора платформенных 404/5xx и завершится ошибкой, если проблема сохранится.
- Background Sync зависит от Android/Chrome. Надёжный запасной путь — открыть приложение с сетью и нажать «Синхронизировать». Не очищать данные сайта до отправки очереди.
- Приложение сериализует собственные запросы через Durable Object. Одновременная ручная сортировка/правка Google Sheets не защищена атомарной транзакцией; не выполняйте её во время записи из приложения.
- Перед сменой APP_KEY отправить очередь. После выхода очередь сохраняется отдельно для прежнего кода.
- Дополнения к ТЗ: стабильный `id` обязателен в quick/save для безопасных повторов; числовая дата и RAW-текст сохраняют формат A и исключают вычисление пользовательских формул. Фронтенд-этапы проверялись совместно. Все решения — [DECISIONS.md](DECISIONS.md).
- Необязательные редактирование лимитов/доходов, импорт Excel и сверка с выпиской Kaspi не реализованы. Следующий практический шаг — проверить MacroDroid на реальных уведомлениях и первую настоящую трату на телефоне.
