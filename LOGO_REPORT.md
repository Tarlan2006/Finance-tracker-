# LOGO_REPORT — Finance Tracker

Дата: 31 октября 2026. Задание: LOGO_PROMPT.md.

## Результат

Утверждённый логотип из трёх растущих столбцов на чёрном фоне внедрён без изменения геометрии и цветов. Единственный редактируемый исходник — web/public/icons/logo.svg. Файл favicon.svg генерируется из него; компонент Logo встраивает тот же исходник через Vite ?raw, без отдельного запроса при отображении.

| Файл в web/public | Размер | Назначение |
|---|---:|---|
| icon-192.png | 192×192 | any, прозрачные скруглённые углы |
| icon-512.png | 512×512 | any, прозрачные скруглённые углы |
| icon-maskable-512.png | 512×512 | maskable, сплошной чёрный квадрат |
| apple-touch-icon.png | 180×180 | Apple, полностью непрозрачный чёрный фон |
| favicon.svg | SVG viewBox 512×512 | Векторная вкладочная иконка |
| favicon-32.png | 32×32 | PNG-запасной favicon |
| icon-monochrome-512.png | 512×512 | monochrome, только чёрные столбцы на прозрачном фоне |

Manifest разделяет any, maskable и monochrome; name и short_name остаются Finance Tracker, оба фоновых цвета — #000000. HTML подключает SVG/PNG favicon и apple-touch-icon. Старый icon.svg и прежний scripts/icons.mjs удалены.

На входе знак 72 px, в шапке 28 px, рядом с названием. Он декоративный (aria-hidden), не добавляет фокусируемых элементов, отдельной анимации нет. Финансовая логика, worker/, shared/, зависимости и запись в Google Sheets не изменялись.

## Генерация и проверки пикселей

Команды:

- node scripts/make-icons.mjs — генерация через установленный Playwright Chromium/Canvas.
- node scripts/make-icons.mjs --check — повторная генерация в памяти и побайтная сверка со всеми PNG/SVG.
- node scripts/logo-contacts.mjs — контактные листы после браузерных тестов.

Генерация и --check дали одинаковые файлы. Chromium: 156.0.8078.4; шрифты не используются. Детерминированность проверена в этой версии Chromium, идентичность PNG между разными версиями браузера не обещается. Новых зависимостей нет.

Проверены 32 244 пикселя переднего плана с ненулевой альфой: максимальный радиус **185,2742 px** при разрешённых **204 px**, запас **18,7258 px**. Проверка относится к столбцам: сплошной чёрный фон maskable по назначению занимает весь квадрат. Прозрачных/полупрозрачных пикселей в maskable и Apple — **0**. У any-иконок и PNG favicon углы прозрачны. У monochrome фон прозрачный, ненулевых цветовых каналов нет.

## Не проверено на физическом телефоне

Физический Samsung Galaxy S25 FE, установка Android WebAPK, тематические иконки Android, iOS Home Screen и Safari не проверялись. Проверены файлы и их пиксели, Chromium, эмуляция размеров/касания, сервис-воркер и HTTP-ответы. Форма squircle на контактном листе — геометрическая иллюстрация маски; конкретный launcher может использовать свою форму.

**Чтобы увидеть новую иконку на телефоне, установленное приложение нужно удалить и установить заново. Перед этим отправьте офлайн-очередь. Android кеширует иконку WebAPK; сохранение старого значка до переустановки — не ошибка приложения.**

Решения: DECISIONS.md. Пользовательские LOGO_PROMPT.md и Claude outputs/ не изменялись и в наши коммиты не включались.
